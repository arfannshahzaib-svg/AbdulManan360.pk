
# 🌿 StudyHub — Student Portal

A modern, responsive student portal with a fresh green design.

## Features

- Responsive mobile-friendly design
- Home Page
- Login Page UI
- Student Dashboard
- Admin Dashboard
- CEO Dashboard
- Student Result Card
- Search results by roll number
- Print results or save as PDF
- Green and white interface

## Technologies

- HTML5
- CSS3
- JavaScript

## Demo Login

The current version uses demonstration login navigation only.
It does not provide real authentication or separate secure accounts.

## Installation

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For online hosting, enable GitHub Pages in repository Settings.

## GitHub Pages

1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select the `main` branch and `/ (root)`.
5. Click Save.

## Custom Domain

Configure your domain under Settings → Pages.
Add the DNS records required by your domain provider.

## Important

This project is currently a front-end demonstration.
Real login authentication, persistent student records,
and secure Admin/CEO permissions require a backend.
